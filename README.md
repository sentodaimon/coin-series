# Bitcoin Coin Series

Bitcoin Half, Quarter, Dime, Nickel and Cent — five independent blockchains that keep Bitcoin's transaction system, multiply the supply by 2, 4, 10, 20 and 100, and use a newly designed mining, difficulty and distribution scheme.
